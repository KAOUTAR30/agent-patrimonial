# Agent patrimonial

Agent d'aide à l'analyse patrimoniale, construit avec langGraph et un LLM local (Qwen via Ollama)
projet en cours de construction.

l'agent part des informations dont dispose le conseiller(avis d'imposition, versementconstatés, biens déclarés).
Il ne calcule que ce que ces documents ne donnent pas : "l'effet d'une décisions future"
